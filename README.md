# Digivigee Landing Page

Production-ready, highly polished landing page built with **Next.js 16**, **React 19**, **Tailwind CSS v4**, and **WebGL Volumetric Particle Engine**.

## Getting Started

Run the development server:

\\\ash
npm run dev
\\\

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploying to Vercel

1. Push this folder to a new GitHub repository:
   \\\ash
   git init
   git add .
   git commit -m "Initial commit of Digivigee Landing Page"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   \\\
2. Go to [Vercel](https://vercel.com) and click **Add New Project**.
3. Import your GitHub repository.
4. Framework will be automatically detected as **Next.js**.
5. Click **Deploy**!

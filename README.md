# Dr. Noopur Patel — Breast Cancer Surgeon

> Specialist Medical Web Platform for **Dr. Noopur Patel**, Breast Cancer Surgeon & Associate Consultant in Surgical Breast Oncology at **Marengo CIMS Hospital, Ahmedabad, Gujarat, India**.

---

## 🏥 About the Practice

Dr. Noopur Patel is dedicated to comprehensive, compassionate, and evidence-based breast surgical oncology. Her clinical practice focuses on:
- Breast Cancer Diagnosis & Evaluation
- Surgical Breast Oncology
- Oncoplastic Breast Surgery (volume preservation & reshaping)
- Breast-Conserving Surgery (BCS / Lumpectomy) & Sentinel Lymph Node Biopsy
- Mastectomy (skin-sparing / nipple-sparing)
- Benign Breast Conditions Management

---

## 🚀 Technology Stack

- **Framework:** [Next.js 16 (App Router & Turbopack)](https://nextjs.org/)
- **UI & Architecture:** [React 19](https://react.dev/) + TypeScript
- **Styling:** Custom Medical Design System + Tailwind CSS
- **Typography:** Playfair Display (Editorial Serif) + Inter / Plus Jakarta Sans
- **Database & Sync:** Firebase Client SDK (Firestore, Auth, Storage, Analytics)
- **Accessibility:** WCAG 2.2 AA Compliant
- **Structured Data:** Schema.org `Physician`, `MedicalBusiness`, and `WebSite` JSON-LD

## 🌐 Deploy to Vercel / Cloud

1. Push to your GitHub repository:
   ```bash
   git push -u origin main
   ```
2. Connect the repository in [Vercel](https://vercel.com).
3. Set the Environment Variables from `.env.local`.
4. Deploy!
